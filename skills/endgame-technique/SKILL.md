# 残局要领

**特征**：一方大子明显减少。**残局是闷摆的重灾区**——
实测有对局在这里连续 27 手无吃无将、双方各搬各的。

**标签怎么读**（残局标注少，`过河` 权重最高）：`吃X` 优先，`占中`/`占肋` 次之；`抽X` 必得子。

## 别闷摆（残局头号问题）

**判据**：连续两手都无吃无将、对方也无应对压力——已在闷摆，立刻换法。

1. **进兵提速**——多一个过河兵就接近胜负手，推进本身就是内容。
2. **主动兑子**——兑掉僵持大子，加速进入有胜负的阶段。
3. **制造接触**——能吃就吃，能将就将，别拿闲手试探。
4. **残局禁弃子**——子力精确、每兵必争，轻率弃子直接失败。

**底线**：无吃无将的搬运**超过 3 手**即失误。宁可走不吃便宜但有推进的棋。

## 核心原则

- **兵卒价值倍增**：过河兵卒是胜负手
- **将帅参与战斗**：残局中帅将可以助攻
- **优势方快速入局**：尽快结束战斗，不给对方喘息

## 求和路线（规则性，别搞错）

**不要靠「长将」求和**——单方长将**立即判负**，不是判和。
合法求和只有四类**允许着法**：**兑、献、拦、跟**。

因此劣势方求和靠**制造兑子机会**或主动「献」子，而非反复将军或制造重复局面。
反过来，**主动送对方和棋等于放弃**，除非已无翻盘可能。

长打细则（禁止着法、循环首着吃子扣除）见 `check-defense` 与 `repetition-management`。
