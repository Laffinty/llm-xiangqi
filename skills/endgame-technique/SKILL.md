# 残局要领

**特征**：一方大子明显减少，技术重要性凸显。

**标签怎么读**（残局子力少，标注也少，`过河` 权重最高）：`吃X` 优先，
`占中`/`占肋` 次之；`抽X` 出现时基本必得子。

**核心原则**

- **兵卒价值倍增**：过河兵卒在残局是胜负手
- **将帅参与战斗**：残局中帅将可以助攻
- **优势方快速入局**：迅速结束战斗，避免对方求和
- **劣势方谋和**：寻找兑子或制造重复局面求和

**子力价值换算**（粗略）

| 子力 | 残局相对价值 |
|---|---|
| 车 | 9 |
| 马 / 炮 | 4.5 |
| 兵 / 卒（过河） | 2 |
| 相 / 象 | 2 |

**和棋路线**：己方无攻势时，优先制造对方无法回避的重复局面。但注意——**主动送对方和棋等于放弃**，除非已无翻盘可能。
