# 棋风执行细则

> L3 参考：仅在被激活 skill 显式引用时载入（`PLAN-SPECTACLE-001` `P-02`）。

## 各型的典型起手取向

- **进攻型**：优先 `弃X` 与 `抽X`，宁可把局面搅复杂。
- **稳健型**：优先 `兑子` 与 `占肋`，用子力优势慢慢兑现。
- **灵活型**：不按固定套路，善用 `过河`、`占中` 制造意外节奏。
- **防守反击型**：稳住阵型等对手露出破绽，再抓住窗口反击。

## 与其他 skill 的分工

- `middlegame-tactics` 管**中局的战术、节奏与弃子判据**，本 skill 管**取向一致性**。
  稳定的进攻型棋风，本就要靠中局的「别闷摆」纪律来执行。

## 为什么「不摇摆」

「战术密度」随手一波动就改棋风，等于没有棋风。棋风要在**整局**层面保持，
这样观者能看出双方在下不同的棋，这本身就有看头。

## 常见误区

- 进攻型 ≠ 每步都冲。盲目送子反而丢子，**弃子要满足 `middlegame-tactics`
  里的三条判据**。
- 稳健型 ≠ 消极。稳健是「用低风险手段积累优势」，不是「什么都不做」。
- 劣势换风格求侥幸是最差的选择——换风格不改变子力，只打乱自己的计划。
