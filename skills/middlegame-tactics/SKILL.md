# 中局要领

**特征**：战斗打响，局面复杂多变。

**核心原则**

- **目标优先**：每步棋都要有明确目的（攻杀 / 牵制 / 封锁 / 运子）
- **计算深度**：关键局面计算 3-5 步后的变化
- **子力交换**：得子得先则换，失子失先则避
- **王的安全**：时刻关注己方将帅安全

**战术优先级**

1. `抽X`（同时攻击多子）——必得子，优先考虑
2. `将军` + 吃子——双重威胁，但要预判对方应手后是否有后续
3. `牵制`——不直接得子，但限制对方关键子力，为后续创造条件
4. `弃X`——只在有明确后续收益时使用，否则是纯粹亏损

**目标设定**：从 `annotated_moves` 中挑出战术项集中的走法，围绕它们构建 3-5 回合计划，而不是逐手被动应对。

详见 `references/move-values.md`。
