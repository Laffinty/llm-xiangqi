# 走步价值判断参考表

> L3 参考：仅在被激活 skill 显式引用时载入（`PLAN-SPECTACLE-001` `P-02`）。
> 本表在原战术优先级基础上，补入**观赏性**维度。

| 情况 | 观赏性 | 说明 |
|------|--------|------|
| 将军 + 弃子 | ★★★★★ | 把对方应手压到最少，是最易算的弃子 |
| 抽大子 / 捉双 | ★★★★★ | 必得子，同时攻击多子 |
| 吃大子（车） | ★★★★☆ | 得子占优 |
| 主动弃子（成立） | ★★★★☆ | 有后续收益的牺牲 |
| 占中 / 占肋 | ★★★☆☆ | 战略要点，有内容但不刺激 |
| 单纯将军 | ★★★☆☆ | 检查对方应手，无后续则寡淡 |
| 兑子简化 | ★★☆☆☆ | 求稳，但对局易走向平淡 |
| 重复搬运 | ★☆☆☆☆ | 闷摆，观感最差 |

**读法**：高星不等于必走。优先选**高分且有后续**的着法；
若只有低分着法，宁可从中挑「对手最难应」的那个，也不要连续走无压力闲手。
