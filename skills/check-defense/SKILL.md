# 应将要领

**前提**：`in_check` 为真，你已被将军。**先解将，再谈其他。**

**应手优先级**

1. **吃掉将军子**——若将军子无保护且可吃，直接消除威胁
2. **堵住将路**——移动被攻击的将/帅，或用己方子堵住连线格
3. **移开被攻击子**——被将军的是己方攻子时，把它挪开或用子保护
4. **弃子解将**——用价值较低的子吃掉将军子，保留将帅

**必须检查的连带风险**

- 解将后是否仍然被将？
- 解将用的子是否挡住了己方其他棋子的进攻路线？
- 是否解将后立刻丢子？

**长将不是出路——它会直接判负**

按《象棋竞赛规则》，**单方长将立即判负**（不是判和）。长杀、长捉、一将一杀等交替循环属**禁止着法**，同样不变判负；合法求和只有四类允许着法：**兑、献、拦、跟**。

因此解将后若仍处劣势，应**制造兑子机会**或改变子力结构，不要用连续将军换和棋。
