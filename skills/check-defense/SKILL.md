# 应将要领

**前提**：`in_check` 为真，你已被将军。**先解将，再谈其他。**

**应手优先级**

1. **吃掉将军子**——若将军子无保护且可吃，直接消除威胁
2. **堵住将路**——移动被攻击的将/帅，或用己方子堵住连线格
3. **移开被攻击子**——被将军的是己方攻子时，把它挪开或用子保护
4. **弃子解将**——用价值较低的子吃掉将军子，保留将帅

**必须检查的连带风险**

- 解将后是否仍然被将？（多重攻击）
- 解将用的子是否挡住了己方其他棋子的进攻路线？
- 是否解将后立刻丢子？那样只是把将帅换成别的东西亏。

**长将不是出路**：连续将军在象棋中可能判负。解将后若仍处劣势，优先考虑**制造重复局面**求和，而不是硬撑。
